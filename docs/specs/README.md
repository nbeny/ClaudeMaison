# `docs/specs/`

Specs détaillées par service.

Vide pour l'instant — chaque service obtient sa spec au moment de son démarrage, suivant le cycle :

1. Brainstorming (voir doc d'architecture pour le périmètre fonctionnel).
2. Spec écrite ici (`specs/<service>/design.md`).
3. Plan d'implémentation.
4. Code.

Le doc d'architecture donne la _vision_ ; les specs donnent les _contrats_.
