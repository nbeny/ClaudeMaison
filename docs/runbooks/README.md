# `docs/runbooks/`

Procédures opérationnelles. Vide pour l'instant — à peupler au fur et à mesure que des incidents ou opérations récurrentes émergent.

- `incident-gpu-saturation.md`

- `rotate-vault-secrets.md`

- `scale-gpu-pool.md`

## Format

Chaque runbook commence par :

- **Quand l'utiliser** (signal d'alerte précis)
- **Pré-requis** (accès, outils)
- **Étapes** (numérotées, copiables)
- **Vérification** (comment savoir que c'est résolu)
- **Post-mortem** (lien vers le template)
